## Key Concepts Learned
### Semantic HTML
Semantic elements describe the purpose of page content. For example,
`nav` is used for navigation links and `footer` is used for footer content.

### CSS Selectors
Selectors allow CSS rules to target HTML elements. I used class selectors
to style reusable parts of the page.

### Box Model
The CSS box model consists of content, padding, border, and margin.
`box-sizing: border-box` makes width and height easier to control.

### Flexbox
Flexbox is useful for arranging items in one direction. I used it for the
navigation bar and for aligning the contents inside cards.

### Grid
CSS Grid is useful for two-dimensional layouts. I used it to arrange the
six course cards in rows and columns.

### Hover Effects
The `:hover` pseudo-class changes an element's appearance when the mouse
pointer moves over it.

### Responsive Design
Media queries change the layout according to screen width. The cards show
three columns on large screens, two on tablets, and one on mobile screens.

## Challenges and Solutions
### Challenge 1 — Keeping Cards Consistent
Some cards contained different amounts of text. I solved this by using
Flexbox inside each card and allowing the card content to fill the available
space.

### Challenge 2 — Making the Cards Responsive
The cards initially stayed in one fixed layout when the screen became small.
I solved this by studying CSS Grid and media queries and changing the grid
from three columns to two and finally one column.

### Challenge 3 — Navigation Spacing
The navigation links needed consistent spacing and alignment. I used Flexbox
with `gap`, `align-items`, and `justify-content` to arrange them.
